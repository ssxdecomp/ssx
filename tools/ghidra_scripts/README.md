# Ghidra Scripts

This folder contains scripts for use with Ghidra.

# Installation

You will need to make sure you are using PyGhidra; see the [Ghidra Getting Started](https://github.com/NationalSecurityAgency/ghidra/blob/stable/GhidraDocs/GettingStarted.md#pyghidra-mode) document for instruction how to run Ghidra with PyGhidra support.

Add this folder as a script source in the Script Manager.
